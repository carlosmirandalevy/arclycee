💻 Código Abierto

Todo el código de ArcLycée está disponible públicamente en GitHub. Puedes descargarlo, estudiarlo, modificarlo y aprender de él.

Repositorio GitHub

El código fuente completo del juego está alojado en:

github.com/carlosmirandalevy/arclycee

Cómo clonar el proyecto

Si tienes Git instalado, abre una terminal y ejecuta:

git clone https://github.com/carlosmirandalevy/arclycee.git
cd arclycee

¡Eso es todo! No necesitas instalar nada más. ArcLycée usa HTML5 Canvas + JavaScript vanilla — sin frameworks, sin compilación, sin dependencias.

Cómo ejecutar el juego localmente

Necesitas un servidor HTTP local porque los módulos ES6 no funcionan con file://. Cualquiera de estas opciones sirve:

# Con Python (viene preinstalado en Mac/Linux)
python3 -m http.server 8000

# Con Node.js
npx serve .

# Con PHP
php -S localhost:8000

Luego abre http://localhost:8000/juego.html en tu navegador.

¿Por qué código abierto?

ArcLycée fue creado por estudiantes de 13 años del Liceo Francés de Santo Domingo como parte del curso de Robótica. Creemos que:

  • El conocimiento debe ser libre — si un grupo de estudiantes de 13 años puede crear un RPG educativo, queremos que otros puedan aprender de nuestro código.
  • El código es legible — todo está documentado en español, con comentarios extensos pensados para que otros estudiantes puedan entenderlo.
  • La arqueología es de todos — el patrimonio arqueológico dominicano merece ser difundido por todos los medios posibles.

¿Qué puedes hacer con el código?

  • Estudiarlo — leer cómo funciona un juego 2D hecho desde cero con JavaScript vanilla
  • Modificarlo — cambiar niveles, añadir personajes, traducir a otros idiomas
  • Aprender — usar el código como base para tus propios proyectos educativos
  • Contribuir — enviar pull requests con mejoras, correcciones o contenido nuevo

Tecnologías utilizadas

  • HTML5 Canvas — todo el renderizado del juego
  • JavaScript vanilla (ES modules) — sin frameworks, sin bundlers
  • Web Audio API — 57 efectos de sonido procedurales (sin archivos de audio para SFX)
  • LeafletJS — mapa de referencia real de La Hispaniola (la única librería externa)
  • CSS puro — toda la documentación que estás leyendo
