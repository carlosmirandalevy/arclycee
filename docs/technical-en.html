Design Principles

  • Readability first: code commented in Spanish, readable by 13-year-old students
  • No heavy dependencies: only LeafletJS for maps, everything else vanilla
  • Procedural sound: effects generated with Web Audio API, no files
  • Programmatic sprites: all characters and buildings drawn with Canvas 2D
  • 3 languages: Spanish, French, and English — every visible string is translated

Scene Lifecycle

Each scene implements:

  • iniciar(juego) — initial setup when entering
  • actualizar(dt, entrada, jugador, companeros) — per-frame logic
  • dibujar(renderizador, ancho, alto, textos, jugador, companeros) — rendering

Scene change with juego.cambiarEscena('name'). Only one scene active at a time.

Save System

Auto-save when returning to map. Serialized data:

  • Current scene, character gender, language
  • Player health
  • Progress (completed and unlocked nodes)
  • Full inventory (items with name, description, type)
  • Companions (type + active/inactive state)

"Continue Game" in the main menu restores everything and goes to the map.
