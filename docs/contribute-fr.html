🤝 Contribuer

ArcLycée n'est pas un projet terminé — c'est un projet vivant. Chaque semaine, de nouveaux mondes, personnages, mécaniques, questions, traductions et corrections sont ajoutés. Si vous voulez faire partie de cette aventure, il y a de nombreuses façons de contribuer.

Un projet en développement continu

ArcLycée est né dans le cours de Robotique du Lycée Français de Saint-Domingue en 2026, et n'a pas cessé de grandir depuis. Ce qui a commencé comme un prototype avec un seul monde est devenu un RPG éducatif avec 13 mondes, 600 questions, une encyclopédie complète et une bande originale.

Mais il reste encore beaucoup à faire. Chaque nouvelle version apporte des améliorations, et chaque joueur qui essaie le jeu nous aide à découvrir ce qui fonctionne et ce que nous pouvons améliorer. Le développement ne s'arrête jamais.

Comment contribuer

  • Signaler des bugs — Vous avez trouvé un bug, une erreur de traduction ou quelque chose qui ne fonctionne pas ? Envoyez-nous un message ou ouvrez une issue sur GitHub.
  • Suggérer des améliorations — Vous avez une idée pour un nouveau monde, personnage, question de quiz ou mécanique ? Nous serions ravis de l'entendre.
  • Traduire — Le jeu est trilingue (ES/EN/FR), mais pourrait s'étendre à d'autres langues. Si vous maîtrisez une autre langue et souhaitez aider, contactez-nous.
  • Créer du contenu éducatif — Vous êtes enseignant et avez des activités qui fonctionneraient avec ArcLycée ? Nous pouvons les intégrer dans le Guide d'Apprentissage.
  • Contribuer du code — Le dépôt est ouvert. Faites un fork, implémentez votre amélioration et envoyez une pull request. Lisez la page Clonez-nous pour commencer.
  • Créer de l'art ou de la musique — Vous savez dessiner, animer ou composer de la musique ? Le jeu a toujours besoin de plus de ressources visuelles et sonores.
  • Faire passer le mot — Partagez le jeu avec d'autres enseignants, élèves, parents ou passionnés d'archéologie dominicaine.

Pour les élèves

Si vous êtes élève et que la programmation vous intéresse, ce projet est une excellente opportunité d'apprentissage. Tout le code est documenté en espagnol, conçu pour être lisible par des élèves de 13 ans. Vous pouvez :

  • Lire le code source et comprendre comment fonctionne un jeu 2D créé de zéro
  • Modifier un monde existant ou en créer un nouveau
  • Ajouter des questions à la banque d'évaluation
  • Concevoir un nouvel ennemi ou PNJ avec sa propre histoire
  • Améliorer l'accessibilité du jeu

Pour les enseignants

ArcLycée a été conçu pour la salle de classe. Si vous l'utilisez dans vos cours, votre expérience est inestimable :

  • Dites-nous quelles activités ont le mieux fonctionné avec vos élèves
  • Suggérez des sujets que nous devrions couvrir dans l'encyclopédie ou les quiz
  • Partagez les supports pédagogiques que vous avez créés à partir du jeu
  • Aidez-nous à améliorer la documentation pédagogique

Pour les archéologues et historiens

La précision historique et scientifique est une priorité du projet. Si vous êtes spécialiste en archéologie dominicaine, histoire taïno, écologie caribéenne ou patrimoine culturel :

  • Révisez notre contenu et signalez les inexactitudes
  • Suggérez des sources académiques que nous pouvons incorporer
  • Aidez-nous à enrichir l'Archepédie avec des informations vérifiées

Contactez-nous

Le moyen le plus simple de nous joindre est via le formulaire de contact. Vous pouvez aussi ouvrir une issue ou pull request directement sur GitHub.

Chaque contribution compte. D'une correction orthographique à un monde entier — tout nous aide à faire d'ArcLycée une meilleure ressource éducative pour la République Dominicaine et les Caraïbes.
