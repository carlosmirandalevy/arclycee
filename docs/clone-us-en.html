💻 Open Source

All of ArcLycée's code is publicly available on GitHub. You can download it, study it, modify it and learn from it.

GitHub Repository

The complete source code of the game is hosted at:

github.com/carlosmirandalevy/arclycee

How to Clone the Project

If you have Git installed, open a terminal and run:

git clone https://github.com/carlosmirandalevy/arclycee.git
cd arclycee

That's it! You don't need to install anything else. ArcLycée uses HTML5 Canvas + vanilla JavaScript — no frameworks, no build step, no dependencies.

How to Run the Game Locally

You need a local HTTP server because ES6 modules don't work with file://. Any of these options will work:

# With Python (pre-installed on Mac/Linux)
python3 -m http.server 8000

# With Node.js
npx serve .

# With PHP
php -S localhost:8000

Then open http://localhost:8000/juego.html in your browser.

Why Open Source?

ArcLycée was created by 13-year-old students at the Liceo Francés de Santo Domingo as part of the Robotics class. We believe that:

  • Knowledge should be free — if a group of 13-year-old students can create an educational RPG, we want others to be able to learn from our code.
  • The code is readable — everything is documented in Spanish, with extensive comments designed so other students can understand it.
  • Archaeology belongs to everyone — Dominican archaeological heritage deserves to be shared through every possible medium.

What Can You Do with the Code?

  • Study it — read how a 2D game works, built from scratch with vanilla JavaScript
  • Modify it — change levels, add characters, translate to other languages
  • Learn — use the code as a foundation for your own educational projects
  • Contribute — send pull requests with improvements, fixes or new content

Technologies Used

  • HTML5 Canvas — all game rendering
  • Vanilla JavaScript (ES modules) — no frameworks, no bundlers
  • Web Audio API — 57 procedural sound effects (no audio files for SFX)
  • LeafletJS — real reference map of Hispaniola (the only external library)
  • Pure CSS — all the documentation you're reading
