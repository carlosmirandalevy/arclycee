💻 Code Ouvert

Tout le code d'ArcLycée est disponible publiquement sur GitHub. Vous pouvez le télécharger, l'étudier, le modifier et apprendre de celui-ci.

Dépôt GitHub

Le code source complet du jeu est hébergé sur :

github.com/carlosmirandalevy/arclycee

Comment cloner le projet

Si vous avez Git installé, ouvrez un terminal et exécutez :

git clone https://github.com/carlosmirandalevy/arclycee.git
cd arclycee

C'est tout ! Vous n'avez rien d'autre à installer. ArcLycée utilise HTML5 Canvas + JavaScript vanilla — pas de frameworks, pas de compilation, pas de dépendances.

Comment lancer le jeu localement

Vous avez besoin d'un serveur HTTP local car les modules ES6 ne fonctionnent pas avec file://. L'une de ces options suffit :

# Avec Python (préinstallé sur Mac/Linux)
python3 -m http.server 8000

# Avec Node.js
npx serve .

# Avec PHP
php -S localhost:8000

Ensuite ouvrez http://localhost:8000/juego.html dans votre navigateur.

Pourquoi le code ouvert ?

ArcLycée a été créé par des élèves de 13 ans du Lycée Français de Saint-Domingue dans le cadre du cours de Robotique. Nous croyons que :

  • Le savoir doit être libre — si un groupe d'élèves de 13 ans peut créer un RPG éducatif, nous voulons que d'autres puissent apprendre de notre code.
  • Le code est lisible — tout est documenté en espagnol, avec des commentaires détaillés conçus pour que d'autres élèves puissent le comprendre.
  • L'archéologie appartient à tous — le patrimoine archéologique dominicain mérite d'être diffusé par tous les moyens possibles.

Que pouvez-vous faire avec le code ?

  • L'étudier — lire comment fonctionne un jeu 2D créé de zéro avec JavaScript vanilla
  • Le modifier — changer les niveaux, ajouter des personnages, traduire dans d'autres langues
  • Apprendre — utiliser le code comme base pour vos propres projets éducatifs
  • Contribuer — envoyer des pull requests avec des améliorations, corrections ou nouveau contenu

Technologies utilisées

  • HTML5 Canvas — tout le rendu du jeu
  • JavaScript vanilla (modules ES) — pas de frameworks, pas de bundlers
  • Web Audio API — 57 effets sonores procéduraux (pas de fichiers audio pour les SFX)
  • LeafletJS — carte de référence réelle d'Hispaniola (la seule bibliothèque externe)
  • CSS pur — toute la documentation que vous lisez
