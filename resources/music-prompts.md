# ArcLycée — Suno Music Prompts

Prompts para generar la banda sonora del juego en Suno.
Cada track es un loop de 30-60 segundos, 128kbps MP3.
El estilo general: indie game OST, evocador, memorable, minimalista pero emotivo.

## Tips para Suno

- **Duración**: Pedir "30 seconds" o "60 seconds" según el track
- **Loop**: Siempre incluir "loopable" en el prompt
- **No vocals**: Siempre terminar con "No vocals"
- **Iteración**: Generar 3-4 variantes y elegir la mejor
- **Formato**: Exportar como MP3 128kbps para mantener tamaño bajo
- **Naming**: Usar los nombres de archivo sugeridos arriba
- **Carpeta destino**: `resources/music/`
